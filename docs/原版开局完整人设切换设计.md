# 原版开局完整人设切换设计

## 目标

1.7 正式版默认使用带动态适配槽位的通用人物档案。安装内置“原版·桐城皂隶篇”后，桐城相关人物应改用旧版角色卡中的完整人设；卸载身份 DLC 后，必须精确恢复安装前的人设内容。

该切换只处理 15 个经过动态化改造的 SFW 条目。其余历史人物 SFW 条目与旧版内容一致，无须重复写入；NSFW 条目继续保持独立、默认关闭，不跟随身份 DLC 切换。

## 资源位置

固定的旧版完整人设模板存放于：

`src/cmyj-1.7/statusbar/original-tongcheng-character-profiles.json`

资源随状态栏脚本一起构建，不依赖玩家本地保留旧版角色卡，也不产生额外网络请求。每项资源只包含正式世界书中的条目名称与完整正文：

```json
{
  "version": 1,
  "profiles": [
    {
      "entryName": "苏晚棠_SFW",
      "content": "<苏晚棠_SFW>……</苏晚棠_SFW>"
    }
  ]
}
```

旧版人物概览另存于：

`src/cmyj-1.7/statusbar/original-tongcheng-character-overview.json`

它将旧卡的“桐城人物概览”和“外地女角概览”名单合并为一个常驻蓝灯条目“人物概览”。概览只保留姓名、身份、亲属关系与必要出处，不写年龄、性格、能力评价或剧情倾向。该条目不再根据三种开场裁剪名单，原版开局中的桐城、紫禁城、江南、安庆府与流寇人物会同时保留。

原版人物谱系图另存于：

`src/cmyj-1.7/statusbar/original-tongcheng-relationship-graph.json`

该资源恢复旧版状态栏的固定人物分组、节点与连线，共 27 个节点和 27 条关系。节点说明与新版“人物概览”保持一致，只写人物身份和关系，不写年龄或性格。人物谱系属于身份 DLC 的界面上下文，不读取会随剧情变化的 MVU“人际网络”变量。

## 安装流程

1. 绑定并校验正式主世界书 `残明余烬1.7`。
2. 如果存在其他身份 DLC，先按其安装记录完成卸载和恢复。
3. 校验 15 个目标条目全部存在；任一缺失则停止安装，不做部分替换。
4. 将每个目标条目的当前完整 `content` 保存为 `characterProfileBackups`。
5. 只替换目标条目的 `content`，保留触发词、启用状态、插入位置、顺序和递归配置。
6. 安装唯一的原版“人物概览”条目，内容包含旧版两份人物概览的全部名单和身份关系。
7. 将原版人物谱系写入身份 DLC 的 `ui.relationshipGraph`。
8. 将备份、人物概览版本、人物谱系版本和条目数量写入 `character.extensions.canming_dlc`。
9. 如果角色卡扩展写回失败，立即用本次备份回滚世界书内容。

安装记录的核心结构：

```js
{
  characterProfileBackups: [
    {
      entryName: '苏晚棠_SFW',
      previousContent: '安装前的 1.7 动态人设正文'
    }
  ],
  context: {
    originalCharacterProfileVersion: 1,
    originalCharacterProfileCount: 15,
    relationshipGraphVersion: 1,
    ui: {
      relationshipGraph: {
        categories: [],
        nodes: [],
        links: []
      }
    }
  }
}
```

## 卸载与切换

卸载时先用 `characterProfileBackups` 恢复完整正文，再处理旧版本可能遗留的 `characterAdaptationBackups`，最后恢复开场白、世界书附加条目并清除身份 DLC 标记。

切换至其他身份 DLC 时复用同一卸载路径，因此其他 DLC 看到的一定是恢复后的 1.7 动态人设，而不是原版人设。

## 兼容与幂等

- 已安装新版原版开局且资源版本、条目数量一致时，重复点击安装不会再次备份或覆盖。
- 从旧版原版开局迁移时，先恢复旧的动态适配块，再生成整份动态人设备份并安装完整人设。
- 修复操作保留同样的“恢复后重装”顺序，避免把原版人设误当成动态人设备份。
- 已安装原版开局但人物概览版本过旧或正文不完整时，重复点击安装会将其修复为单条目的完整概览。
- 已安装原版开局但人物谱系版本缺失或过旧时，重复点击安装会补写谱系上下文；重新载入状态栏后生效。
- 完整人设资源不进入通用开局生成器；云端或自制身份 DLC 仍使用原有的动态适配机制。
